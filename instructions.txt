Welcome to the Pokemon Battle Simulator!


To run the program, you must execute it from the terminal, via the command line.

By default, the program will look for a file called "trainers.txt", which will contain how many and which
Pokemons each trainer will have. To use a file with another name, use '--file [FILE NAME]' in the command line.

The file must follow the following structure:

M N
Pokemon 1 Attack Defense Health Type
.
.
.
Pokemon M Attack Defense Health Type
Pokemon 1 Attack Defense Health Type
.
.
.
Pokemon N Attack Defense Health Type

M and N are the number of Pokemons of Trainer 1 and 2, respectively. They must be a positive number less than or equal to 100.

"Attack", "Defense" and "Health" must be integers.

"Type" must be one of the Pokemon types contained in:
{"electric", "water", "fire", "ice", "rock"}, without quotes, always without accents and in lowercase.

For more questions, type '--help' in the command line.

To compile the program, use cargo build

Have fun battling!
